# 对比页的完整公开读取 · 2026-10-28

部分由源码维护的产品对比已有完整 HTML，却没有可发现的 Markdown/JSON，也未进入公开资料库。自动发布的对比已有独立导出，不能让新增静态格式抢回已经发布的版本。

为现有三篇静态对比生成六个中英文完整版本：保留原文介绍、比较表、选择建议、核验日期、官方来源和测试范围，不改写事实或把旧核验日期改成今天。HTML、目录、MCP 与 CLI 复用同一份内容，提供稳定的章节标识和 canonical 链接。新增的是阅读格式，不是六篇新文章。

格式入口放在正文末尾，避开手机端会隐藏的既有侧栏；独立留白、标签与可换行布局让英文和中文都可直接使用，JavaScript 未运行时同样可见。

将这些对比加入既有知识索引；公开 MCP 支持完整或按章节读取。已经被编辑版本增强的 canonical 仍只发现一个当前文档，原有编辑 ID 与新静态 ID 都读取当前版本，原文部分的章节标识继续有效。未知章节仍报错，引用元数据不冒充外部原文读取。

静态机器版本使用 noindex、可跟随链接和精确 HTML canonical。构建时从真实双语索引生成每个导出文件的 canonical 头，避免通配规则把 compare 文件指向 learn。HTML 声明替代格式与 encoding，不凭空增加发布日期或修改核验日期；移动端保持现有侧栏节奏。

同一篇内容的 Markdown/JSON 复用一个文件名前缀规则，并在构建与审计中限制规则总数及行长，遵守 [Cloudflare 静态资源头规则限制](https://developers.cloudflare.com/workers/static-assets/headers/)。不同 canonical 不共享宽泛的目标替换规则。

补充 [KnowTarot](https://www.knowtarot.com/) 与 [NTTarot](https://nttarot.net/en/features) 的已核对官方来源和独立对比蓝图：前者围绕学习、记录与复盘流程，后者围绕实体牌记录、存储与上下文流转。功能描述属于厂商公开说明，未测试账户或付费能力；选题与关键词仍是研究假设。蓝图进入原有来源读取、写作、独立审稿和原子双语发布流程，不新建定时器或绕过质量门槛。

归属判断同样复用完整知识数据。原先传入的基础段落缺少已上线的图解、示例、表格和 FAQ，可能把旧答案误认成新增价值；现在传入与公开 JSON 相同的完整双语内容及目录。已保存的决定保持原样，后续研究和发布审稿读取修复后的范围；这不预先判定某个候选一定能通过，也不自动扩张预算。

验证覆盖完整表格和来源、双语/章节范围、静态到编辑增强版本的替换与旧 ID、公开 MCP、CLI、构建后的 canonical/noindex 头、目录和实际下载。执行必要回归、只读 Grok 检查、PR/CI、部署、线上格式与模型无关读取；单独记录模型发布、搜索提交、实际收录和流量，不从导出可用推断增长。
