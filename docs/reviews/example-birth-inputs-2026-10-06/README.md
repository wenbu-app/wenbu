## 日期与计算边界

- 保持原来的 1901–2099、公历、24 小时制和后端计算规则。
- 一位月份、日期、小时、分钟规范化为现有 API 格式。未填项保持未填；不会擅自补成 00:00。
- 闰日按公历验证；无效年月日、24 点、60 分和无效时区在表单处阻止提交。
- 支持 `1990-08-16`、`1990/8/16`、`1990年8月16日`、`19900816` 和全角数字粘贴；不猜测 `08/06/1990` 的月日顺序。
- “时间未知”切回已知保留刚才的时间；未知时间切至紫微后仍要求填写时、分。真太阳时仍必须已知时间和经度。
- 示例说明同步改为选择“时间未知”，避免继续提示一个无法提交的空白时间。
