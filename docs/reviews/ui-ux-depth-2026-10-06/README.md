# Wenbu 深度 UI / UX 研究、系统修复与验收

日期：2026-10-06，Asia/Shanghai。范围：当前仓库生成的全部 93 个页面（中英文首页、四种工具、Agent、手记、知识手册、文章、比较页、开发者说明、账号入口与 Insights），以及关键交互、失败恢复和发布一致性。

本轮在现有产品上改善可读性、动作稳定性和状态可信度。纸感、鼠尾草绿、朱砂色、原创牌面与封面继续沿用。研究建议用于指导实现；转化、留存与真实使用效果仍需要发布后的数据和用户观察。

## 结论与流程健康度

1. **了解产品 → 找到入口：通过已检查路径。** 全站辅助文案原先偏淡；统一可读色值。知识手册保留配图、阅读路径、主题筛选与搜索，移走遮挡内容和“查阅出处”的悬浮反馈按钮。反馈在页脚、工具结果和 Agent 中仍可进入。
2. **开始对话 → 补充上下文 → 查看结果：通过本地模拟路径。** 入口选项直接开始对话；模式与结果筛选具有可读取的选中状态。手机切换到结果时进入面板，返回时焦点回到入口。增加长对话“回到最新消息”，保留主动阅读历史的位置。发现并修复焦点提示导致按钮在按下与松开之间移动的问题；复验滚动距底部 0.5px、焦点回到对话、返回按钮消失。
3. **使用工具 → 保存 → 再次阅读：通过已检查路径。** 四种工具的空状态说明各自需要什么。手机八字拼音、藏干与五行从 7–8px 提升至 10px；英文五行用英语展示。手记编辑和数据刷新保留当前阅读项；搜索支持工具名；移除和恢复只有写入成功后才显示成功。账号入口继续允许先完成体验，提供“继续不注册”，邮箱账号用于云端保留与跨浏览器继续。
4. **阅读手册 / 牌义 → 查看图解：通过已检查路径。** 中英文卡片、图文、目录、来源与 Agent 导出结构保留。牌库筛选现在说明显示数量；大阿卡纳显示 22 张，放大原图、关闭与 Escape 返回正常。插画加载失败增加明确状态与重试，牌义不丢失；这一故障分支做了源码检查，未做浏览器网络拦截验收。
5. **反馈 / 统计 → 失败恢复与数据解释：通过已检查路径。** 空反馈将焦点带到可补充的字段。服务失败保留原文和提交编号，错误为中英文可操作说明。只有 `saved: true` 且编号匹配才显示已收到。本地模拟 503 后恢复并重试，D1 仅有一个对应回执。Insights 的正文、说明和图例统一对比；错误保留上一份报告；时间区间、时区、测试数据开关、曲线与表格替代可使用。

这次没有阻塞已检查核心路径的已知缺陷。186 次页面布局检查不等于每个状态、每种设备都已验证；下面单独列出证据范围与未验证项。

## 研究依据与应用

| 依据                                                                                                | 对 Wenbu 的判断与实际应用                                                                                                                                    | 约束                                                                                            |
| --------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------- |
| [W3C：文字最低对比](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)              | 普通文字按 4.5:1 检查。原 `#6c7368` 在纸色上约 4.42:1；将辅助文字统一为 `#596657`，暖色辅助文字使用独立可读 token。共享纸色、浅纸色、sage 表面加入数值回归。 | 不能把 4.42 四舍五入为通过。装饰线和纯装饰符号与正文分开；扫描不等于完整 WCAG 认证。            |
| [W3C：最低目标尺寸](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)           | 手机 Agent 常用按钮、模式、资料入口与牌面关闭提高到 44px 高度或 44×44；320px 英文收起次要标签。                                                              | AA 2.5.8 的最低要求是 24px 或满足间距/例外；44px 是本产品的触控设计目标，不能说成 AA 强制标准。 |
| [W3C APG：模态对话框](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)                       | 使用现有 native dialog；检查初始焦点、Escape、关闭后返回。结果切换也有明确焦点去向。                                                                         | 本轮没有完成所有屏幕阅读器与操作系统组合的验收。                                                |
| [W3C：状态消息](https://www.w3.org/WAI/WCAG22/Understanding/status-messages.html)                   | 筛选结果、反馈保存/失败和表单错误使用 status/alert 或 aria 描述；成功必须绑定真实回执。                                                                      | 提示准确性优先于泛化的“成功”；浏览器标识不能表述为真实人数。                                    |
| [NN/G：Less Chat, More Answer，2026-04-17](https://www.nngroup.com/articles/less-chat-more-answer/) | 用户应快速看到结构清晰的成果。保留对话与独立结果面板，提升正文阅读尺寸，把原始计算结果、来源和适用范围说清楚；无引用报告不再声称基于所读资料。               | 该研究的场景不能直接证明 Wenbu 用户偏好；本轮把它作为设计假设，没有宣称转化提升。               |
| [NN/G：渐进披露](https://www.nngroup.com/articles/progressive-disclosure/)                          | 先提出问题、得到结果；需要出生资料、手记上下文或高级统计筛选时再展开。保留帮助入口与清楚的选择状态。                                                         | 不把必要信息藏掉，也不把所有功能变成强制问卷。                                                  |
| [W3C：交互动画](https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions.html)       | 保留事件驱动的生成仪式、暂停开关与系统减少动效偏好；这次优先处理滚动、焦点和按钮稳定性。                                                                     | 2.3.3 是 AAA 条款。没有额外添加循环动画或人为等待来暗示计算进度。                               |

## 验收方法和证据范围

- [完整路由清单](layout-routes.json)直接来自当前构建，93 页，不使用手工猜测的 URL。
- [手机 375×812](layout-mobile.json)与[桌面 1280×900](layout-desktop.json)：每组 93 页，均无整页横向溢出、可见破图或检查范围内的文字低对比候选。每页 H1 / 标题亦有记录。Agent 另验 320×812；Insights 登录后另验 375px。
- 对比扫描读取实际 DOM/CSS，普通文字 4.5:1、大字 3:1；不把隐藏、禁用、装饰或透明度变化中的元素当成正文。最近的不透明背景是近似规则，图片/渐变合成、所有状态、完整键盘顺序、所有屏幕阅读器不在自动扫描结论中。
- Agent 用一次本地选择回答生成模拟研究报告；资料弹窗关闭回到入口，移动结果切换焦点往返，最新消息动作有数值回执。模型明确标为 `local-fixture`，不代表 DeepSeek 本次已验。
- 本地真实 Worker 计算验收：紫微命宫点选、易经手动六爻与动爻、八字已有手记阅读；塔罗牌库筛选 22 张与原图放大。后续生产 smoke 单独记录四种计算 API。
- 账号检查本轮浏览器覆盖邮箱入口与“继续不注册”，没有真实注册或发送邮件。原生 Worker/D1 套件覆盖模拟 OTP、账号隔离、保存回执与限制。
- 统计以一次性本地 D1 合成数据检查 1 天 24 小时、UTC/北京时间、曲线/完整表格、测试流量开关，账户统计有独立筛选说明。相关截图：[小时表格](after/12-insights-hourly-desktop.png)、[小时曲线](after/13-insights-chart-desktop.png)。合成数据不能作为站点增长证据。
- [工程校验](verification.log)：0 类型错误 / 警告 / 提示；26 文件、318 单元测试；64 原生 workerd/D1 账号检查；93 页面、4,835 站内引用、86 索引页面；78 牌面/78 缩略图；42 完整双语知识版本；站点、牌面、知识与 IndexNow 清单审计均通过。[ESLint](lint.log)与 `git diff --check` 通过。Node 依赖加载产生的实验/弃用诊断保留在日志中，不与类型检查结果混为一谈。
- 新增测试覆盖桌面/触屏/IME 键盘约定，底层错误隔离，反馈错误本地化与回执匹配，以及共享色板真实对比数值。没有用实现镜像测试替代操作验收。
- 增加可复用的 `scripts/smoke-build.mjs`：比较 18 个核心中英文路由及直接引用 JS/CSS 的完整字节，防止发布后仍服务旧界面。先在一次性本地 Worker 验证，再独立对正式站执行。
- [Grok 尝试记录](grok-review.txt)：只读 patch review 两次均未返回结论；第一次超 8 分钟后停止，第二次 120 秒期限后超时。**没有 Grok 通过结论**，不将独立测试冒充外部审查。

## 发布与后续观察

最终源码、PR / CI、Cloudflare 版本、线上字节匹配及 smoke 回执将在发布后补在此节。当前本地证据是验收记录，不应被解释为正式站已更新。

发布后应观察“开始探索 → 完成操作 → 保存意图 → 邮箱验证 → 有效云端保存 → 再次使用”的分层数据，以及反馈里的阅读、误触与弱网问题。注册按钮点击不等于注册，注册不等于有效保存；浏览器 ID 不等于自然人。本轮不能证明流量、注册转化或留存已经增长。
