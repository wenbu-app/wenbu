# Wenbu UI / UX 系统检查与修复

日期：2026-10-05。范围：现有中英文站点、四种工具、Agent、知识手册、手记、账号保存、反馈与 Insights。保留现有纸感、配色、插画和生成仪式，不重做产品结构。

## 发现与处理

| 路径                   | 发现                                                                     | 修复                                                                                                                        |
| ---------------------- | ------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------- |
| 游客工具结果 → 保存    | “保存”把本地写入与账号登录混在一起                                       | 明确分为“保存在此浏览器”与“免费保存到账号”；前者不打开注册                                                                  |
| 保存 → 邮箱验证 → 返回 | 保存语境弱；取消后的意图可能继续被使用；成功后仍留在账号设置             | 展示当前结果名称、验证并保存、成功后返回原结果；关闭或普通账号入口清除旧意图；异步操作用代次隔离                            |
| 云端保存反馈           | 账号已连接不能证明当前结果已保存；实际复验发现云端成功后仍显示浏览器保存 | 按记录区分未保存、本机、待同步、失败与云端回执；刷新云端缓存后通知订阅者；新增回归测试                                      |
| Agent 完成成果         | 手机用户不易发现账号保存的价值                                           | 成功回合且有报告/排盘等成果后，显示可关闭的保存邀请；澄清、错误、取消与生成中不显示；每个标签页会话最多一次，关闭后七天抑制 |
| 手机导航               | 打开标签不随状态变化，键盘返回不明确，底层工作区仍能交互                 | 中英文打开/关闭标签、当前路由标识、Escape 返回触发器、底层主内容 inert；点击外部与宽屏恢复关闭                              |
| 英文与窄屏             | Insights 全中文；短中文标签换成英文后缺少统一处理                        | 统计概览、图表、筛选、定义、历史、反馈、归档和账号统计完整英文；保留用户提交原文；选中态采用有 pressed 状态的按钮组         |
| Insights 时间          | 详情时间按浏览器时区显示，可能与已应用筛选不一致                         | 按已应用时区格式化详情时间；账号统计旧响应在取消后不再覆盖新筛选                                                            |
| 阅读与表单             | 小屏输入字小；Agent 宽表格缺键盘入口                                     | 关键移动输入 16px；结果操作可换行；Agent 表格增加可聚焦、带名称的横向滚动区                                                 |
| 工具解释               | 示例结果缺显著标识；手动六爻仍叫随机起卦                                 | 标注示例出生资料；手动输入按钮改为“读取这组六爻”                                                                            |
| 手记                   | 搜索无结果后缺直接恢复入口，页眉仍为 About                               | 加清除搜索按钮并恢复输入焦点；页眉改为手记                                                                                  |
| 官网与手册             | 仍介绍已删除的草稿向导、仅本地保存和按网络的旧额度                       | 修正首页、工具 FAQ、对比页、入门/复盘指南、关于页；保留免注册试用；区分游客/账号额度与网络防滥用上限                        |
| 内容更新日期           | 文章 HTML 可取单篇日期，知识 JSON 却忽略它                               | HTML / Markdown / JSON 使用同一单篇更新日期，索引取最新指南日期                                                             |
| 事件含义               | `result_viewed` 容易被误读为真实阅读                                     | 保留事件名兼容，后台标为收到结果；邀请可见、点击、关闭与账号面板打开分开记录                                                |

## 实际界面验证

- 生产修改前检查：桌面 1280、手机 375 与 320；包含首页、Agent、手册、文章、四种工具、手记、接入、牌组、对比、Insights。部分首次截屏处于 hydration 阶段，不将其当作稳定失败证据。
- 本地修改后：22 条路线的 375px 布局矩阵，以及 7 条桌面路线矩阵；无页面级横向溢出，检查时已加载图片无损坏，未发现可见无名称按钮。见 [手机矩阵](after/mobile-route-matrix.json)、[桌面矩阵](after/desktop-route-matrix.json)。这是模板与 DOM 校验，不等于逐像素审阅所有文章。
- 额外复验 768 / 820 / 1024px：820px 英文主导航原本被挤成两行，已把导航折叠断点调整为 1024px，桌面标签保持单行。菜单展开后切回桌面会关闭菜单并解除主内容的 inert；手记清除搜索后恢复完整列表与输入焦点。
- 实际点击验证：菜单打开/关闭和 Escape、必填日期聚焦、八字/紫微示例、塔罗抽取、本地保存、主动云端保存、取消后普通登录、模拟 OTP 保存与返回同一结果、账号手记重新读取、搜索空状态、Agent 澄清→成果→关闭邀请→查看报告、知识手册搜索/空状态恢复/分类/列表。
- Insights 使用**一次性本地 D1、模拟数据**验证：默认排除测试、包含测试切换、一天 24 个时段及未来空值、三十天 30 个时段与小时选项禁用、图表/数据表切换、概览筛选继承到历史。截图数字不是生产使用量。
- 在正常页面提供减少动效开关/系统偏好，保留已有功能。本轮没有新增无意义循环或延迟；没有完成所有真实手机、全部浏览器及独立屏幕阅读器合规认证。

## 工程校验

- `npm run verify`：0 类型错误 / 警告，310 单元测试、64 项本地 workerd / 原生 D1 账号检查通过。
- 构建 93 页；4,835 个站内引用、86 个可索引页、78 张牌面及缩略图、42 份完整双语知识 HTML/Markdown/JSON、IndexNow 清单一致性检查通过。
- `npm run lint` 与 `git diff --check` 通过。
- 导航断点的最后一处 CSS / 媒体查询修复后，重新构建并通过站内引用与 IndexNow 清单审计；UI 已在 820 / 1024px 复验。CI 将验证最终提交。
- 新增回归保护：按记录判断回执、离线/暂停时不谎报云端成功、普通入口不携带旧意图、导入完成通知读取者、全量指标定义/过滤标签英文映射。

- 邮箱验证为一次性本地模拟投递，不证明真实收件箱送达；模型回答为本地 fixture。本次 UI 修复不改变模型或计算算法。
