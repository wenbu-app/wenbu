## 实现约定

- 首屏给出四句完整、自然的开场白，以及“还没想好”入口。点选直接发送按钮上的句子，不经过表单、预览或草稿。
- 塔罗、易经、资料研究保留在可展开入口；研究示例直接使用 research 模式，普通主题使用 explore。
- Agent 在对话中问一个关键问题；选项直接回复，“我自己说”聚焦唯一的聊天输入框。对方不确定时继续澄清，不代填事实。
- 每个选择只发送自己的文本；未发送草稿保留原文，既不覆盖，也不混入请求。空选项不回退发送草稿，超长消息不静默截断。
- 报告追问、结果继续和出生资料提交也统一走提交入口。只有选中的出生资料作为上下文发送，未知时刻仍保留未知。
- 发起请求前同步上锁，防止双击重复执行；加载中、执行中、超长、达到会话上限时不记作已开始。
- 快捷回复后焦点留在新消息，流式结束不抢焦点或打开手机键盘；必要资料窗口关闭后恢复到已提交消息。
- 仅成功的纯澄清回合隐藏重复工具说明、结束仪式和结果评价。真正失败的工具仍显示；研究与结果的仪式、来源和反馈保留。
- 旧版步骤埋点不再发送，历史标签注明旧版；真正提交继续使用 agent_started，并区分入口、澄清、追问、示例、自由输入。见 [分析口径](../../analytics.md#agent-提问引导)。
- 旧向导、草稿拼接、过时样式已删除，减少维护两套交互的风险。

浏览器用独立本地预览，真实 Worker 路由 + 合成模型响应，不发送邮件、不调用真实模型。启动：先构建，再运行 `WENBU_PREVIEW_GUIDANCE=1 node scripts/preview-accounts.mjs`。合成答复只验证交互，不用于声称 DeepSeek 的回答质量。

实际验收包括：入口双击只生成一个用户消息；澄清点击、键盘 Enter 追问均直接提交；中文及英文草稿在点选后完整保留；“我自己说”回到输入框；出生日期使用真实键盘事件更新并在预览核对后继续，未知时刻保留；320px/375px 无横向溢出，主要点击区域至少 44px。新引导的次要文字调整到至少 4.5:1 的对比度；320px 的语言切换保持单行。日期字段的自动 fill 只改变 DOM 值，未触发 React 更新；验收改用真实键盘事件后，预览与提交一致。
