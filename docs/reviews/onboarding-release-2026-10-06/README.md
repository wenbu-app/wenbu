# 轻试用、完整结果与统计校准

2026-10-06。承接[下一阶段体验研究](../../research/onboarding-next-experience-2026-10-06.md)。用户已授权优化并部署，并要求产品界面不再强调模型供应商。

## 本轮实现

- Agent 首屏保留自由输入，突出单张正位试用、八字资料入口和完整示例。话题提示按需展开。单牌按钮明确使用一回合；不会先问个人资料。若已有选中背景或历史消息，使用新的空白上下文开始这项轻试用，原会话和未发送草稿保留。
- 示例顶部可直接开始对应实践。固定星星牌仍明确标为编辑示例；实践按钮发起真实随机抽取。命盘实践打开所需表单，不往输入框拼入一段待发送的说明。
- 同一回合的原始牌面／命盘与完整解读在结果面板关联展示；导出也包括原文。只派生展示视图，不重写带签名的对话、原结果或凭据，不再请求一次模型摘要。未完成的文本不当作完整解读。
- 聊天中的塔罗结果有原始牌面缩略图、名称与方向。追问围绕当前牌或行动，保存预览说明牌名、对话全文及结果数量；注册仍由用户主动点击保存触发。
- 独立工具可将当前结果及用户填写的背景带入新的 Agent 对话。复用已有账号缓存和签名结果，不新建身份存储；URL 只含不透明的会话标识。进入后先显示选中结果，确认发送才开始解释；不自动重抽。首次解读将已校验的原始结果快照纳入带签名的会话，单独保存会话后也可复原，不依赖另一份游客手记仍在浏览器中。示例命盘不走个人结果的快捷承接。
- UI、营销与知识页不再展示供应商品牌或型号。保留通用 AI 处理说明、服务商隐私政策链接及技术记录中的真实服务元数据。后端 API、模型配置和配额保持原接入。
- 浏览器事件和 Clarity 共用 cookie／session 测试标记；读取任一存储失败不会掩盖另一个标记。无法读取 session 标记时，第三方录屏保持关闭。保存邀请曝光需要至少 50% 可见且页面在前台。
- 账号统计升级为 `account-v3`：近期试用与已完成 7 天观察的转化队列分列，分子和分母来自同一成熟队列；D1、D7 各用已完成观察的激活日期窗口，并显示日期。未满期不计入成熟分母；无样本不显示成 0% 转化。

## 发布后补充修复

线上控制台发现 React 418 初始化渲染差异：多个 Astro React 区块共用账号 store，较早加载的区块可能在另一区块 hydrate 前更新账号状态。`useSyncExternalStore` 的 server snapshot 原来直接读取实时状态，因而与构建 HTML 不同。统一改为稳定的初始 server snapshot，完成 hydrate 后再订阅实时状态。四处账号 UI 一并修复；新增账号已提前加载时的回归测试。本地带真实账号 API 的预览，以及补丁后的生产新标签页，中英文 Agent 与英文塔罗连续导航均不再产生该错误。
